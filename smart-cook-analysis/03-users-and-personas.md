## 2. الشخصيات (Personas)

### 👩‍👧 أم سارة — 38 سنة، موظفة وأم لثلاثة (الرياض)
- **السياق:** تعود الخامسة مساءً، لا وقت للتفكير.
- **الألم:** تكرار نفس الأطباق، مكونات تفسد في الثلاجة.
- **ما تريده:** فتح التطبيق → رؤية «عشاء جاهز بما لديك» → طهي.
- **مقياس نجاحها:** قرار العشاء في أقل من دقيقة.

### 🎓 خالد — 22 سنة، طالب جامعي مغترب (القاهرة/كوالالمبور)
- **السياق:** مطبخ مشترك، ميزانية ضيقة، ثلاثة مكونات أساسية.
- **الألم:** يشتري ثم يهدر، يأكل خارج البيت كثيرًا.
- **ما يريده:** وصفات رخيصة، صور واضحة، لا مصطلحات صعبة.
- **مقياس نجاحه:** وجبات أقل من 15 دقيقة، وتقليل الطلب من الخارج.

### 🧑‍💼 ليلى — 29 سنة، تتبع حمية خالية من الغلوتين (دبي)
- **الألم:** فحص كل وصفة يدويًا.
- **ما تريده:** فلتر حمية يُطبَّق تلقائيًا، وتنبيهات صارمة للمكونات المحظورة.
- **مقياس نجاحها:** ثقة كاملة بأن النتائج آمنة.

### 👨‍🍳 أبو محمد — 55 سنة، يحب الطبخ التقليدي (عمّان)
- **الألم:** التطبيقات الأجنبية لا تفهم أطباقه.
- **ما يريده:** وصفات أصيلة بمقادير صحيحة، ونصائح تقليدية.
- **مقياس نجاحه:** وجود الطبق الذي يبحث عنه بنسخته الأصيلة.

## 3. رحلة المستخدم الأساسية (Core Journey)

```
[فتح التطبيق لأول مرة]
   → اختيار اللغة/اللهجة والبلد (يؤثر على أسماء المكونات والوحدات)
   → أسئلة سريعة (حساسية؟ حمية؟ عدد الأفراد؟) — يمكن تخطيها
   → «ماذا لديك اليوم؟» إدخال أول مكونات (3 طرق)
   → أول نتيجة سحرية: «يمكنك طهي 24 طبقًا الآن»
   → اختيار وصفة → وضع الطهي
   → بعد الطهي: تقييم + تحديث المخزون تلقائيًا
   → إشعار مسائي لطيف في اليوم التالي
```

## 4. سيناريوهات الاستخدام (Use Cases)

| # | السيناريو | المخرج المتوقع |
|---|-----------|-----------------|
| U1 | لديّ دجاج وأرز وبصل | قائمة أطباق (كبسة، أرز بالدجاج، …) |
| U2 | أخبر التطبيق صوتيًا: «عندي بيض وبندورة وجبنة» | يتعرّف ويضيف 3 مكونات ويعرض نتائج |
| U3 | تصوير الثلاجة | قائمة مكونات مقترحة للتأكيد |
| U4 | ينقصني مكوّن واحد | يعرض «ينقصك: كريمة؛ بدائل: لبن + زبدة» |
| U5 | ضيوف غير متوقعين | فلتر «سريع + يُقدَّم لـ 6 أشخاص» |
| U6 | مكوّن سيفسد غدًا | «استخدمني اليوم» ببطاقة تحذير ووصفات |
| U7 | رمضان | «وصفات الإفطار/السحور» بالمتاح |
| U8 | حساسية مكسرات | استبعاد صارم + تحذير على كل وصفة |
| U9 | لا إنترنت | المطابقة والوصفات المحفوظة تعمل |

## 5. نقاط الألم → حلول التصميم

| نقطة الألم | الحل |
|------------|------|
| إدخال المكونات ممل | صوت + كاميرا + «مكونات شائعة» + الاستكمال التلقائي + تذكّر الأساسيات |
| «ليس عندي شيء مناسب» | ظهور «ينقصك مكوّن واحد» + بدائل + «ألهمني» (الذكاء الاصطناعي) |
| الخوف من فشل الوصفة | وصفات مجرَّبة، صور لكل خطوة، نصائح «لا تفعل كذا» |
| يدي مبتلتان وأنا أطبخ | وضع صوتي، أزرار ضخمة، شاشة لا تنطفئ |
| الاختلاف في الأسماء/الوحدات | محرك مرادفات ومحوّل وحدات حسب البلد |
| القلق من الحساسية | فلتر صارم + تحذير بصري أحمر |
