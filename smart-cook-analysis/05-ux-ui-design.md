# 05 — تجربة المستخدم وواجهة الاستخدام (UX/UI)

> الهدف: تجربة تضاهي أفضل التطبيقات العالمية في الفئة، وتتفوق عليها في الدقة الثقافية وسلاسة العربية.

## 1. فلسفة التصميم

| المبدأ | التطبيق |
|--------|---------|
| **شهية بصرية** | صور الطعام بطولها الكامل، ألوان دافئة، ظلال ناعمة، دون ازدحام |
| **قرار سريع** | بطاقة واحدة = قرار واحد؛ أهم معلومة (الوقت + التغطية) ظاهرة دائمًا |
| **تقدم تدريجي** | لا نسأل إلا ما نحتاجه الآن (Progressive disclosure) |
| **أيدي مشغولة** | أهداف لمس كبيرة وأوامر صوتية في وضع الطهي |
| **الاحتفاء الصغير** | حركات دقيقة عند الإنجاز، دون إفراط |
| **RTL أولًا** | التصميم يبدأ من اليمين لليسار، ثم يُرآى للإنجليزية |

## 2. بنية المعلومات (Information Architecture)

شريط تنقل سفلي (5 عناصر كحد أقصى):

```
🏠 اليوم   |   🥕 مطبخي   |   ✨ اكتشف   |   📅 الخطة   |   👤 أنا
```

| التبويب | المحتوى |
|---------|---------|
| **اليوم** | «ماذا نطبخ الآن؟»: اقتراحات جاهزة، تحذير الفساد، وصفة مسائية |
| **مطبخي** | المخزون بتصنيفات، إضافة سريعة (صوت/كاميرا/كتابة)، الأساسيات |
| **اكتشف** | بحث بالوصفات، مطابخ، مجموعات موسمية، «ألهمني» |
| **الخطة** | مخطط الأسبوع + قائمة التسوق |
| **أنا** | المفضلة، التفضيلات، الحساسية، الاشتراك، التصدير |

## 3. الشاشات الرئيسية (Wireframes نصية)

### 3.1 شاشة الترحيب (Onboarding) — 3 شاشات كحد أقصى
```
┌──────────────────────────┐
│     [رسم متحرك: ثلاجة     │
│      تتحول إلى طبق]      │
│                          │
│  لا تسأل «ماذا نطبخ؟»    │
│  اترك الأمر لنا          │
│                          │
│  [ ابدأ الآن ]  (تخطي)   │
└──────────────────────────┘
```
ثم: اختيار اللهجة/البلد → أسئلة اختيارية (حساسية، حمية، عدد الأفراد) → **مباشرة إلى إضافة المكونات** (بلا تسجيل).

### 3.2 «مطبخي» — إضافة المكونات
```
┌──────────────────────────────────┐
│ 🔍 ابحث أو قل ما لديك...   🎤 📷 │
├──────────────────────────────────┤
│ شائع لديك:                        │
│ (بيض) (بصل) (طماطم) (دجاج) (أرز) │ ← شرائح قابلة للنقر
├──────────────────────────────────┤
│ لديك الآن (7)                     │
│ 🥚 بيض   🍅 طماطم   🧅 بصل  ...  │
│  ⏳ حليب — ينتهي غدًا            │
├──────────────────────────────────┤
│ [ شاهد 18 وصفة يمكنك طهيها → ]   │ ← زر ثابت بالأسفل
└──────────────────────────────────┘
```
- العدّاد الحي «شاهد X وصفة» يتغير مع كل إضافة (مكافأة فورية).
- الاستكمال التلقائي يدعم اللهجات: كتابة «بندو» تقترح «بندورة/طماطم».
- **الصوت:** زر ميكروفون كبير، يظهر النص المسموع مباشرة، ثم شرائح للتأكيد.
- **الكاميرا:** إطار توجيه، صورة متعددة، ثم شاشة تأكيد: «وجدنا 9 مكونات — هل هذا صحيح؟»

### 3.3 «اليوم» — الاقتراحات
أقسام أفقية:
1. **جاهز الآن** (تغطية كاملة) — بطاقات كبيرة.
2. **ينقصك مكوّن واحد** — مع ملصق «ينقصك: كريمة».
3. **تستخدم ما سيفسد** — «استخدم الحليب اليوم».
4. **سريع (≤20 دقيقة)**.
5. **ألهمني ✨** (ذكاء اصطناعي).

**بطاقة الوصفة:**
```
┌────────────────────┐
│ [صورة كبيرة]   ♡   │
│ ⏱ 25د · 😊 سهل · 🍽 4│
│ كبسة الدجاج          │
│ ✅ لديك 9/9 مكونات   │
└────────────────────┘
```
عناصر: شريط تغطية (حلقة تقدم)، رمز حمية/حساسية، شارة «موثّق ✓» أو «مقترح بالذكاء الاصطناعي ✨».

### 3.4 صفحة الوصفة
- صورة علوية متمددة (parallax خفيف).
- شريط معلومات: الوقت، الصعوبة، السعرات، عدد الأفراد (قابل للتعديل).
- المكونات: **متوفر ✅ / ناقص ❌** مع زر «أضِف الناقص للتسوق» وعرض البدائل.
- الخطوات مختصرة + زر ثابت أسفل الشاشة: **«ابدأ الطهي»**.
- أسفل: نصائح الشيف، أخطاء شائعة، تقييمات، وصفات مشابهة.

### 3.5 وضع الطهي (Cook Mode) — الشاشة الأهم
```
┌────────────────────────────────┐
│  الخطوة 3 من 8     ━━━━●────   │
│                                │
│   قلّب البصل في الزيت حتى      │
│   يصبح ذهبيًا                   │
│          (خط ضخم)               │
│                                │
│   [صورة/حلقة توضيحية]          │
│                                │
│   ⏱ شغّل مؤقت 5 دقائق          │
│                                │
│  [ السابق ]     [ التالي ● ]   │
│        🎤 «التالي»              │
└────────────────────────────────┘
```
- شاشة لا تنطفئ، خط كبير جدًا، تباين عالٍ، إمكانية الوضع الليلي.
- **المؤقتات** تظهر كشريط عائم يمكن رؤيته في كل الخطوات.
- لوحة المكونات تُسحب من الأسفل لإعادة التحقق بسرعة.
- عند الانتهاء: شاشة احتفال بسيطة + طلب تقييم + «هل تريد خصم المكونات من مطبخك؟».

### 3.6 قائمة التسوق
- مجمّعة بأقسام السوق، تشطيب بالسحب، أزرار «تم الشراء» تنقل المكوّن إلى المخزون.

## 4. نظام التصميم (Design System)

### 4.1 الألوان
| الدور | اقتراح | الاستخدام |
|-------|--------|-----------|
| الأساسي | برتقالي دافئ/زعفراني `#E8742C` أو أخضر زيتوني `#5B7F3A` | أزرار رئيسية، تركيز |
| الثانوي | أخضر أعشاب `#2F6F4F` | نجاح، «متوفر» |
| الخلفية الفاتحة | كريمي `#FBF7F1` | يخلق دفء الورق/المطبخ |
| الخلفية الداكنة | `#171412` (دافئ لا أسود نقي) | الوضع الليلي |
| تحذير | `#C0392B` | حساسية/ناقص |
| نص | `#1F1B16` / `#F3EEE8` | تباين ≥ 4.5:1 |

(تُعتمد القيم بعد اختبار تباين وصور الطعام الحقيقية؛ يُنصح ببناء Design Tokens في Figma ثم تحويلها لـ `ThemeExtension`.)

### 4.2 الخطوط
- **عربي:** خط حديث مقروء، مثل *IBM Plex Sans Arabic* أو *Cairo* أو *Tajawal* أو *Noto Kufi/Naskh* (تحقق من ترخيص الاستخدام ضمن التطبيق).
- **عناوين:** وزن أثقل وأكبر لتحسين المسح البصري.
- **حجم أساسي:** 16sp، وفي وضع الطهي 24–28sp.
- دعم تكبير النظام (Dynamic Type) حتى 200% دون كسر التخطيط.

### 4.3 المكونات
بطاقة وصفة، شريحة مكوّن (Chip) بحالات: متوفر/ناقص/منتهٍ قريبًا/مستبعد، حلقة تغطية، مؤقت عائم، لوحة صوت، أزرار كبيرة، حالات فارغة مرسومة، هياكل تحميل (Skeletons)، تنبيهات (Snackbars) لطيفة.

### 4.4 الأيقونات والرسوم
- مجموعة أيقونات موحدة للمكونات (حوالي 300 عنصر شائع) بأسلوب رسم واحد.
- رسوم توضيحية للحالات الفارغة والاحتفال بروح محلية دافئة (دون استنساخ شخصيات محمية).

### 4.5 الحركة (Motion)
- انتقال عناصر مشتركة (Hero) من البطاقة إلى صفحة الوصفة.
- إضافة مكوّن: «قفزة» صغيرة + اهتزاز لمسي خفيف.
- العدّاد الحي: رقم يتحرك (count-up).
- مدة 150–300ms، منحنيات ناعمة، **احترام «تقليل الحركة»** في إعدادات النظام.
- Lottie/Rive للاحتفال والتحميل (باعتدال حفاظًا على الأداء).

## 5. تفاصيل RTL الدقيقة

- استخدام `Directionality` تلقائيًا و`EdgeInsetsDirectional` و`AlignmentDirectional` في كل مكان.
- الأيقونات الاتجاهية (سهم رجوع، تقدم) تُعكس؛ أيقونات غير اتجاهية (ساعة، قلب) لا تُعكس.
- الأرقام: خيار «أرقام هندية/غربية» حسب تفضيل المستخدم.
- الكسور والمقادير (½، ¼) تُعرض بشكل سليم في الخطوط.
- اختبار نصوص مختلطة (عربي + إنجليزي + أرقام) لتجنب اضطراب الترتيب (bidi).
- لوحة المفاتيح وحقل البحث يدعمان كتابة اللهجات وإزالة التشكيل والتطبيع (أ/إ/آ → ا، ة/ه، ى/ي).

## 6. الوصولية (Accessibility)

- تسميات `Semantics` لكل عنصر تفاعلي؛ اختبار TalkBack وVoiceOver بالعربية.
- أهداف لمس ≥ 48×48dp.
- عدم الاعتماد على اللون وحده (أيقونة + نص للناقص/المتوفر).
- ملصقات الحساسية بنص وأيقونة وليس لون فقط.
- وضع «نص كبير» وتباين عالٍ.

## 7. المحتوى الدقيق (Microcopy)

| الموقف | النص المقترح |
|--------|--------------|
| حالة فارغة للمطبخ | «مطبخك فارغ؟ لا بأس! قل لنا ما عندك ونحن نتكفّل بالباقي.» |
| مكوّن قريب من الفساد | «الحليب يحتاجك اليوم 🥛 — جرّب هذه الوصفات» |
| لا توجد مطابقة | «ما لقينا طبقًا كاملًا، لكنك تبعد عن X بمكوّن واحد» |
| نجاح الطهي | «بالهناء والشفاء 🍽» |
| خطأ شبكة | «لا إنترنت؟ لا مشكلة، مطبخك يعمل دون اتصال.» |

نبرة: **ودودة، قصيرة، دون مبالغة، بلغة بيضاء مفهومة** مع تخصيص حسب اللهجة اختياريًا.

## 8. اختبار قابلية الاستخدام

1. نماذج Figma تفاعلية → اختبار مع 8–10 مستخدمين من كل شريحة قبل البرمجة.
2. مقاييس: زمن الوصول لأول وصفة، معدل الإكمال، SUS ≥ 80.
3. اختبار A/B لطريقة الإدخال الافتراضية (صوت vs شرائح vs كاميرا).
4. أجهزة اختبار: أجهزة اقتصادية (2–3GB RAM)، وشاشات صغيرة، وأحجام خطوط كبيرة.

## 9. ما يجعل UX «الأفضل بلا منازع»؟ (قائمة التمايز)

1. العدّاد الحي الذي يكافئ كل إضافة.
2. ثلاثة مسارات إدخال سلسة (صوت/كاميرا/كتابة) بلا احتكاك.
3. «ينقصك مكوّن واحد» مع البدائل المتاحة عندك.
4. وضع طهي حر اليدين بمؤقتات ذكية.
5. أداء 60fps وتحميل صور تدريجي (blurhash).
6. عمل دون اتصال.
7. شفافية الذكاء الاصطناعي وثقة المحتوى (شارة «موثّق»).
8. تفاصيل ثقافية: رمضان، اللهجات، الوحدات المحلية.
