# 06 — استراتيجية المحتوى

> المحتوى هو الخندق الدفاعي الحقيقي. الخوارزمية يمكن نسخها؛ مكتبة موثّقة بنكهة محلية يصعب نسخها.

## 1. ركائز المحتوى

| الركيزة | الوصف |
|---------|-------|
| **الأصالة** | وصفات من المطابخ العربية بمقاديرها الصحيحة وأسمائها المحلية |
| **التجريب** | كل وصفة تُجرَّب فعليًا قبل النشر |
| **الوضوح** | خطوات قصيرة، وقت وحرارة محددة، صور للمراحل الصعبة |
| **القابلية للمطابقة** | كل مكوّن مُهيكل (معرّف + كمية + وحدة + مرادفات + بدائل) |
| **الأمان** | تنبيهات حساسية وسلامة غذاء |

## 2. حجم المحتوى المستهدف

| المرحلة | وصفات موثّقة | ملاحظات |
|---------|:------------:|---------|
| MVP | 300–500 | تغطي الأطباق اليومية الأكثر طلبًا، توزيع متوازن بين المطابخ |
| V1 (3 أشهر بعد الإطلاق) | 1,500 | توسّع مطابخ، حمية، رمضان |
| V2 (12 شهرًا) | 5,000+ | بالإضافة لوصفات المستخدمين المراجَعة والمولَّدة المعتمدة |

**توزيع MVP المقترح (تقريبي):**
- الخليجي (كبسة، مجبوس، هريس، مرقوق…): 20%
- الشامي (مقلوبة، محاشي، كبة، فتة…): 20%
- المصري (كشري، ملوخية، محشي…): 15%
- المغاربي (طاجين، كسكسي، شوربة حريرة…): 10%
- العراقي واليمني والسوداني وغيرها: 10%
- عالمي سهل (معكرونة، أومليت، سلطات، دجاج مشوي…): 20%
- فطور/سحور/وجبات خفيفة/حلويات سريعة: موزّعة ضمن ما سبق.

**الأولوية:** وصفات **قليلة المكونات والسريعة** لأنها الأعلى مطابقةً مع ما يملكه الناس فعلًا.

## 3. مصادر المحتوى والحقوق (مهم قانونيًا)

| المصدر | الاستخدام | المخاطر |
|--------|-----------|---------|
| **فريق داخلي من الطهاة/محررين الطعام** | إنشاء وتجريب وتصوير وصفات أصلية | تكلفة، لكنه أفضل خيار ملكية وجودة |
| **تعاقد مع طهاة/مدونين** (ترخيص حصري/غير حصري) | محتوى + جمهور | عقود واضحة للحقوق |
| **اتفاقيات مع ناشرين** | ترخيص مكتبات | تكلفة ترخيص |
| **وصفات المستخدمين** | مع إشراف وموافقة على الترخيص | إدارة الجودة |
| **مولَّدة بالذكاء الاصطناعي** | تُعرَض موسومة وتُراجَع قبل الاعتماد | جودة وأمان |
| **تجميع (Scraping) من المواقع** | ❌ **غير موصى به** | انتهاك حقوق/شروط استخدام؛ جودة متفاوتة؛ خطر قانوني |

> **ملاحظة قانونية:** قائمة المكونات والخطوات الواقعية كحقائق قد لا تتمتع بحماية، لكن **الصياغة والصور والمجموعات** محمية. اعتمد صياغة أصلية دائمًا واستشر محاميًا قبل استخدام أي محتوى طرف ثالث.

## 4. معيار جودة الوصفة (Definition of Done)

- [ ] جُرّبت **مرتين** على الأقل من طاهٍ مختلف.
- [ ] مقادير بالوزن/الحجم بوحدتين (متر/محلي).
- [ ] أوقات وحرارة دقيقة، مع إشارات بصرية للنضج («حتى يصبح ذهبيًا»).
- [ ] صورة نهائية احترافية + صورة لأهم خطوة.
- [ ] وسوم: المطبخ، الوجبة، الحمية، الحساسية، الأدوات، المناسبة.
- [ ] تحذيرات حساسية مفحوصة آليًا ويدويًا.
- [ ] عدد الأفراد، السعرات التقريبية (محسوبة من قاعدة تغذية معتمدة).
- [ ] بدائل مكونات مقترحة (مع أثر البديل على الطعم).
- [ ] مراجعة لغوية بالعربية الفصحى المبسطة (أو اللهجة المقصودة) وخلوها من الأخطاء.

## 5. هيكلة المكونات (قاعدة المعرفة)

كل مكوّن كيان مستقل:

```json
{
  "id": "ing_tomato",
  "names": {
    "ar": ["طماطم", "بندورة", "بنادورة", "قوطة"],
    "en": ["tomato"]
  },
  "category": "vegetable",
  "default_unit": "piece",
  "is_staple": false,
  "allergens": [],
  "diet_flags": {"vegan": true, "halal": true, "gluten_free": true},
  "shelf_life_days": {"fridge": 7, "pantry": 3},
  "substitutes": [
    {"id": "ing_tomato_paste", "ratio": 0.25, "note": "معجون طماطم مخفف بالماء"},
    {"id": "ing_canned_tomato", "ratio": 1.0}
  ],
  "parent": "ing_vegetable"
}
```

**فوائد الهيكلة:**
- **المرادفات واللهجات:** بندورة = طماطم = قوطة.
- **التسلسل الهرمي:** «دجاج» يطابق «صدر دجاج/فخذ دجاج» عند الاقتضاء؛ «جبنة» تشمل الأنواع حسب الوصفة.
- **المكونات الأساسية (staples):** ملح، فلفل أسود، زيت، ماء، سكر… تُفترض ما لم يُعطَّل ذلك.
- **البدائل مع نسب وتأثير:** تقلل الإحباط.

## 6. قاموس اللهجات والوحدات

| العنصر | مثال |
|--------|------|
| مكونات | طماطم/بندورة/قوطة؛ كوسا/كوسة؛ قرع/يقطين؛ بطاطا/بطاطس؛ فلفل رومي/فلفل حلو |
| وحدات | كوب/كاسة/فنجان/استكانة؛ ملعقة أكل/كبيرة؛ ملعقة شاي/صغيرة؛ حبة/حبّة |
| أحجام | «صحن»، «قبضة»، «رشة» — تُحوَّل لقيم تقريبية بالغرام |
| تحويل | ضبط حسب البلد (1 كوب = 240ml تقريبًا وقد يختلف محليًا؛ يُعتمد معيار موحد ويُذكر) |

يُبنى القاموس من: مصادر لغوية + مدخلات فريق المحتوى + **تعلّم من استعلامات المستخدمين** (مراجعة بشرية).

## 7. السلامة الغذائية والحساسية

- **الحساسيات الرئيسية:** مكسرات، فول سوداني، حليب، بيض، سمسم، قمح/غلوتين، سمك، قشريات، صويا.
- أي وصفة تحتوي مسببًا تُوسَم تلقائيًا من هيكلة المكونات (لا يدويًا فقط).
- **تنبيه دائم:** «تحقق من ملصق المنتج؛ التطبيق لا يغني عن استشارة طبية.»
- معلومات سلامة: درجات الحرارة الدنيا للدواجن واللحوم، تحذيرات الأرز المحفوظ، البيض النيء، الأسماك الخام، الأطفال والحوامل.
- **الحلال:** افتراضي. الكحول والمشتقات تُستبعد أو تُوسَم؛ تخصيص من الإعدادات.

## 8. المحتوى الموسمي والثقافي

- **رمضان:** وصفات إفطار/سحور، قوائم أسبوعية، تنبيهات «ماذا على السفرة»، أطباق جاهزة بالمتاح.
- **الأعياد والمناسبات:** حلويات، ولائم، أحجام كبيرة.
- **أيام الامتحانات/السفر:** وجبات سريعة.
- **الشتاء/الصيف:** شوربات، مشروبات باردة.

## 9. التشغيل التحريري

| الدور | المسؤولية |
|-------|-----------|
| رئيس المحتوى | الخطة، الجودة، العلاقات |
| طهاة/محررو وصفات (2–4) | كتابة وتجريب |
| مصوّر/منسّق طعام (متعاقد) | تصوير |
| مراجع لغوي | تدقيق |
| مختص تغذية (استشاري) | سعرات وحميات |
| مهندس بيانات محتوى | هيكلة وضبط الجودة آليًا |

**سير العمل:** فكرة → كتابة → تجريب → تصوير → هيكلة المكونات (أداة داخلية CMS) → فحص آلي (حساسية، وحدات، مرادفات) → مراجعة → نشر.

## 10. حلقة التحسين المستمر

- تقييمات المستخدمين بعد الطهي («نجحت؟ لذيذة؟ أسهل/أصعب من المتوقع؟»).
- وصفات بتقييم منخفض تُراجَع تلقائيًا.
- الاستعلامات التي لا نتيجة لها = **قائمة المحتوى المطلوب** (ما يبحث عنه الناس ولا نملكه).
- تحليل «المكونات الشائعة بلا وصفات كافية» لتوجيه الإنتاج.
