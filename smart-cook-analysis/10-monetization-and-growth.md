# 10 — نموذج الربح والنمو

> الأسعار والنسب تقديرات؛ تُضبط بالاختبار وبحسب القوة الشرائية لكل سوق.

## 1. مبادئ الربح

1. **القيمة الأساسية مجانية** (مطابقة + وصفات + وضع الطهي) حتى يرسخ التطبيق عادةً يومية.
2. **الدفع مقابل التوفير والذكاء والراحة** وليس مقابل أساسيات الطهي.
3. **لا إعلانات مزعجة** في وضع الطهي أبدًا.
4. **شفافية**: لا أنماط مظلمة (Dark patterns) في الاشتراك.

## 2. طبقات المنتج

| الميزة | مجاني | Pro |
|--------|:-----:|:---:|
| إضافة مكونات (كتابة/صوت) | ✅ | ✅ |
| المطابقة والاقتراحات | ✅ | ✅ |
| وصفات موثّقة (المكتبة الأساسية) | ✅ | ✅ |
| وضع الطهي والمؤقتات | ✅ | ✅ |
| المفضلة والتسوق | ✅ | ✅ |
| تصوير الثلاجة | عدد محدود شهريًا | غير محدود (حدود عادلة) |
| «ألهمني» (AI توليدي) | عدد محدود أسبوعيًا | واسع |
| مخطط الوجبات الأسبوعي الذكي | معاينة | كامل + قوائم تسوق |
| البدائل المتقدمة والتعديل الغذائي | أساسي | متقدم |
| مزامنة مع أفراد الأسرة | — | ✅ |
| محتوى حصري (أطباق الشيف، دورات مصغّرة) | — | ✅ |
| بدون إعلانات | — | ✅ |
| تصدير متقدم | ✅ | ✅ |

## 3. التسعير (فرضيات للاختبار)

| الخطة | مثال (دولار تقريبي) | ملاحظة |
|-------|---------------------|--------|
| شهري | 3.99–5.99 | مقارنة مرجعية: منافسون في الفئة يتراوحون تقريبًا بين 5 و10 دولارات شهريًا |
| سنوي | 24.99–39.99 | الأعلى قيمة؛ يُبرَز كخيار افتراضي |
| مدى الحياة (اختياري) | 59–89 | للسيولة المبكرة (يحمل خطر تكلفة AI مستمرة) |
| عائلي | +30% | حتى 5 أفراد |

- **تسعير محلي** حسب الدولة (Purchasing power parity) عبر أسعار المتاجر.
- **تجربة مجانية 7 أيام** بعد إظهار القيمة (ليس قبلها).
- اختبار A/B للـ Paywall: توقيته (بعد أول طهي؟ عند طلب ميزة AI؟)، وصياغته، وعرضه.

## 4. مصادر دخل إضافية

| المصدر | الوصف | ملاحظات |
|--------|-------|---------|
| **عمولات التسوق** | ربط «الناقص» بتطبيقات بقالة/توصيل محلية | يحتاج شراكات؛ لا يؤثر على ترتيب الوصفات |
| **شراكات علامات تجارية** | وصفات برعاية (زيوت، توابل، أجهزة) | وسم واضح «برعاية»، لا تُقدَّم على الجودة |
| **أجهزة المطبخ** | شراكات (قلايات هوائية، أواني) | عندما تُناسب الوصفة فعلًا |
| **بيانات مجمّعة مجهولة** | اتجاهات طلب مواد غذائية (لتجار التجزئة) | **حذر شديد** قانونيًا وأخلاقيًا؛ مجهّلة تمامًا وبموافقة |
| **دورات/محتوى مميز** | سلاسل تعليمية مع طهاة | لاحقًا |

## 5. اقتصاديات الوحدة (مثال تخطيطي، ليس تنبؤًا)

افتراضات توضيحية فقط:
- تنزيلات شهرية: 50,000
- تحويل إلى مستخدم نشط: 40%
- تحويل إلى مدفوع: 3–5% من النشطين (نطاق شائع للتطبيقات الاستهلاكية؛ تحقق من معايير الفئة)
- متوسط عائد/مشترك سنويًا: ~25 دولارًا بعد عمولة المتاجر
- تكلفة AI لكل مستخدم نشط شهريًا: تُقاس (هدفها < 0.05–0.15 دولار)

> **اختبر مبكرًا:** تكلفة الاستدلال بالذكاء الاصطناعي (الصور خاصة) قد تأكل الهامش؛ ضع حدودًا ونموذجًا أصغر وتخزينًا مؤقتًا.

## 6. استراتيجية النمو

### 6.1 ما قبل الإطلاق
- صفحة هبوط + قائمة انتظار (مع «أرسل لنا مكونات ثلاجتك» للحصول على أفكار).
- بناء حسابات سوشيال بمحتوى «ماذا أطبخ بـ…؟» (فيديوهات قصيرة مناسبة جدًا للفئة).
- اختبار مغلق (Beta) مع 200–500 مستخدم عبر TestFlight/Play Internal.

### 6.2 الإطلاق
- إطلاق في سوق/اثنين أولًا (مثلاً السعودية + مصر أو الإمارات + الأردن) ثم التوسع.
- الإطلاق قبل **رمضان** يمنح دفعة طلب كبيرة (يحتاج تخطيطًا مبكرًا).
- حملة مع مؤثري طعام صغار/متوسطين (Micro-influencers): تحدي «ثلاجتي».

### 6.3 قنوات النمو

| القناة | الوصف | الأولوية |
|--------|-------|:--------:|
| **ASO** | كلمات: «وصفات بالمكونات»، «ماذا أطبخ»، «طبخ بما في الثلاجة» (عربي/إنجليزي) | ⭐⭐⭐ |
| **فيديوهات قصيرة** (TikTok/Reels/Shorts) | «فتحنا ثلاجة متابع وطبخنا منها» | ⭐⭐⭐ |
| **محتوى SEO (ويب)** | صفحات وصفات مشتركة + «ماذا أطبخ بـ[مكوّن]» تقود للتنزيل | ⭐⭐⭐ |
| **المشاركة داخل التطبيق** | بطاقات وصفات قابلة للمشاركة بروابط عميقة | ⭐⭐ |
| **الإحالة** | «ادعُ صديقًا، احصل على شهر Pro» | ⭐⭐ |
| **شراكات** | مدونون، منصات وصفات، علامات غذائية | ⭐⭐ |
| **إعلانات مدفوعة** | بعد ضبط الاحتفاظ والتحويل | ⭐ |

### 6.4 حلقات النمو (Loops)
- **حلقة المحتوى:** وصفة مشتركة ← زائر يدخل صفحة ويب ← «أضف مكوناتك» ← تنزيل.
- **حلقة الاحتفاظ:** مخزون أكثر ← اقتراحات أدق ← استخدام أكثر.
- **حلقة الأسرة:** مشاركة المخزون وقائمة التسوق.

## 7. الاحتفاظ (Retention) — الأصعب في الفئة

| الآلية | الوصف |
|--------|-------|
| إشعار «عشاء اليوم» عند الوقت المعتاد | بتخصيص وتحكم كامل |
| «استخدمني قبل الفساد» | قيمة ملموسة |
| تحديات أسبوعية | «طبقان جديدان هذا الأسبوع» |
| سلسلة الأيام (باعتدال) | دون ضغط نفسي |
| ملخص أسبوعي | «وفّرت X من الهدر» |
| وصفات موسمية جديدة | أسبوعيًا |
| تذكير بقائمة التسوق قرب السوق (الموقع، اختياري) | بموافقة صريحة |

## 8. ASO (تحسين الظهور بالمتاجر)

- **العنوان:** اسم + عبارة وصفية («وصفات بالمكونات التي لديك»).
- **كلمات مفتاحية عربية:** طبخ، وصفات، ماذا أطبخ، ثلاجة، مطبخ، أكلات سريعة، رمضان.
- **لقطات الشاشة:** سرد قصة: أضف مكوناتك ← شاهد الوصفات ← اطبخ.
- **فيديو معاينة** 15–30 ثانية.
- **التقييمات:** طلب التقييم بعد نجاح الطهي فقط.
- **الترجمة المحلية** لكل سوق (لهجات في الوصف).

## 9. الاسم والعلامة التجارية (مقترحات للتفكير)

- معيار الاسم: قصير، عربي/عالمي، سهل النطق، متاح كنطاق وحسابات ومتاجر، لا ينتهك علامات قائمة (تحقق قانونيًا).
- اتجاهات: اسم يوحي بالمائدة/الدفء/الذكاء (يُترك الاختيار النهائي لك بعد فحص التوفر).
- هوية: ألوان دافئة، شخصية «شيف ودود» تقدم المساعدة بلا مبالغة.
