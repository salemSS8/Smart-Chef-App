## 2. المتطلبات الوظيفية الأساسية (تفصيل لأهم الميزات)

### FR-1: إدخال المكونات بالصوت
- المستخدم يضغط الميكروفون ويقول جملة حرة.
- النظام يحوّل الكلام لنص (STT) ثم **يستخرج أسماء المكونات** (تحليل نصي + قاموس مرادفات)، ويعرضها كشرائح للتأكيد/الحذف قبل الإضافة.
- شروط القبول: دقة التعرف ≥ 90% على قائمة اختبار من 200 جملة بلهجات متعددة؛ التأكيد البصري إلزامي.

### FR-2: المطابقة
- المدخلات: مجموعة مكونات المستخدم + الأساسيات + المستبعدات + الفلاتر.
- المخرجات: قائمة وصفات مرتبة، كل منها بـ: نسبة التغطية، المكونات الناقصة، البدائل الممكنة.
- شروط القبول: زمن النتيجة < 300ms لقاعدة 10,000 وصفة على جهاز متوسط، وبدون إنترنت.

### FR-3: التعرّف بالصورة
- التقاط صورة/عدة صور، ثم إرسالها لنموذج رؤية (على السحابة أو على الجهاز)، وإرجاع **قائمة مكونات مرشَّحة بدرجة ثقة**.
- المستخدم يؤكد؛ ما دون عتبة ثقة محددة يظهر كـ«هل هذا…؟».
- شرط الخصوصية: حذف الصور بعد المعالجة، وإعلام واضح للمستخدم.

### FR-4: وضع الطهي
- شاشة واحدة لكل خطوة، أزرار كبيرة، نص ≥ 24sp، تباين عالٍ، **عدم إطفاء الشاشة**.
- مؤقتات تُقترح تلقائيًا من نص الخطوة (مثل «اتركها 10 دقائق») وتعمل بالخلفية بإشعار.
- أوامر صوتية اختيارية.

### FR-5: وصفات الذكاء الاصطناعي
- تُولَّد فقط عند طلب المستخدم أو عدم وجود تطابق كافٍ.
- تُوسَم بوضوح «مقترحة بالذكاء الاصطناعي — لم تُجرَّب بعد».
- تمر بفلتر أمان: فحص المكونات الممنوعة، درجات حرارة وأوقات الطهي الآمنة للحوم، تعارض الحساسية.
- يمكن للمستخدم تقييمها؛ الوصفات الممتازة تدخل طابور مراجعة المحررين.

## 3. المتطلبات غير الوظيفية

| الفئة | المتطلب |
|-------|---------|
| **الأداء** | بدء التطبيق < 2 ثانية على جهاز متوسط، 60fps في التمرير، حجم التطبيق < 50MB قدر الإمكان (الصور تُحمَّل عند الطلب) |
| **العمل دون اتصال** | المطابقة، المفضلة، الوصفات المحفوظة، وضع الطهي تعمل Offline |
| **التوافر** | Android 8+ (API 26) وiOS 15+ (تحقق من أحدث متطلبات المتاجر وقت الإطلاق) |
| **اللغة** | عربي RTL افتراضي + إنجليزي؛ بنية جاهزة لإضافة لغات |
| **الوصولية** | دعم قارئ الشاشة، تكبير الخط، تباين WCAG AA، أهداف لمس ≥ 48dp |
| **الأمان** | HTTPS، تخزين آمن للرموز، لا مفاتيح LLM داخل التطبيق، قواعد وصول على الخادم |
| **الخصوصية** | الحد الأدنى من البيانات، موافقة صريحة للتحليلات والصور، حذف الحساب |
| **قابلية التوسع** | الباك اند قابل للتوسع أفقيًا؛ تكلفة الذكاء الاصطناعي مضبوطة بالتخزين المؤقت وحدود الاستخدام |
| **القابلية للاختبار** | تغطية اختبارات الوحدة للمنطق ≥ 80%، واختبارات تكامل للمسارات الأساسية |
| **الرصد** | تتبع الأعطال (Crashlytics/Sentry)، تحليلات الأحداث، تنبيهات الأداء |

## 4. معايير القبول لـ MVP (قائمة تحقق)

- [ ] مستخدم جديد يصل إلى أول نتيجة مطابقة خلال 60 ثانية دون تسجيل.
- [ ] 300–500 وصفة موثّقة بصور حقيقية و5,000 كلمة مفردة/مرادف للمكونات.
- [ ] مطابقة محلية دون إنترنت.
- [ ] وضع طهي كامل بمؤقتات.
- [ ] قائمة تسوق للناقص.
- [ ] إعدادات الحساسية/الحمية تعمل كفلاتر صارمة.
- [ ] واجهة RTL خالية من العيوب البصرية.
- [ ] حذف الحساب والبيانات.
- [ ] اجتياز مراجعة المتجرين.
