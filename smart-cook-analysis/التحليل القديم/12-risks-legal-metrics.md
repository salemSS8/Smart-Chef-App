## 2. الخصوصية والقانون

> **تنبيه:** لست محاميًا. المعلومات التالية إرشادية؛ استشر مختصًا في كل سوق مستهدف.

### 2.1 جدول الأنظمة المحتملة
| النطاق | الأنظمة المرجعية | ما يعنيه للتطبيق |
|--------|------------------|-------------------|
| السعودية | نظام حماية البيانات الشخصية (PDPL) | موافقة، حقوق الوصول والحذف، نقل البيانات خارج المملكة |
| الإمارات | قانون حماية البيانات الشخصية الاتحادي (PDPL) | مشابه |
| مصر | قانون حماية البيانات الشخصية | موافقة، تسجيل |
| الاتحاد الأوروبي | GDPR | إن استُهدف مستخدمون أوروبيون |
| الولايات المتحدة | CCPA/CPRA (ولايات) | حقوق الاعتراض والحذف |
| المتاجر | سياسات Apple/Google | حذف الحساب داخل التطبيق، «ملصق الخصوصية»، فواتير الاشتراك الشفافة |

### 2.2 مبادئ التنفيذ
1. **تقليل البيانات:** لا نجمع ما لا نحتاجه (لا جهات اتصال، موقع دقيق افتراضيًا).
2. **موافقة صريحة ومنفصلة** للتحليلات، والإشعارات، والصور، والموقع.
3. **الصور:** تُرسَل للمعالجة وتُحذف فورًا؛ لا تُستخدم لتدريب نماذج دون موافقة صريحة.
4. **حقوق المستخدم:** تصدير، تصحيح، حذف كامل من داخل التطبيق.
5. **الأطفال:** التطبيق موجّه لعمر 13+ (أو 17+ بحسب خصائص المتجر)؛ لا استهداف إعلاني للقصّر.
6. **مزودو الخدمات:** اتفاقيات معالجة بيانات، وتحديد مواقع التخزين.
7. **سياسة الخصوصية وشروط الاستخدام** بالعربية والإنجليزية بلغة مبسّطة.
8. **إخلاء المسؤولية الغذائي:** معلومات التغذية والحساسية إرشادية، وليست نصيحة طبية.

### 2.3 الملكية الفكرية
- وصفات أصلية بصياغة خاصة؛ صور مملوكة أو مرخّصة؛ خطوط وأيقونات بترخيص يسمح بالتضمين التجاري.
- فحص اسم التطبيق وشعاره (علامات تجارية).
- شروط استخدام لمحتوى المستخدمين (ترخيص غير حصري لنا) وآلية الإبلاغ والإزالة.

### 2.4 إعلانات الذكاء الاصطناعي
- وسم وصفات AI بوضوح.
- عدم الادعاء بأنها «مجرّبة» أو «آمنة طبيًا».
- قياس وتوثيق ضوابط السلامة (مفيد عند أي نزاع).

## 3. مؤشرات النجاح (KPIs)

### 3.1 نمو
| المؤشر | التعريف |
|--------|---------|
| التنزيلات | عدد التثبيتات حسب القناة |
| CPI / CAC | تكلفة اكتساب مستخدم |
| تفعيل (Activation) | مستخدمون أضافوا ≥ 3 مكونات وشاهدوا نتائج في الجلسة الأولى |

### 3.2 تفاعل
| المؤشر | الهدف الأولي |
|--------|--------------|
| DAU/MAU | ≥ 20% |
| جلسات أسبوعية لكل نشط | ≥ 3 |
| نسبة «بدء الطهي» من الجلسات | ≥ 25–35% |
| إكمال الطهي من البدء | ≥ 60% |

### 3.3 جودة
| المؤشر | الهدف |
|--------|-------|
| تقييم المتجر | ≥ 4.6 |
| معدل خلو الأعطال (crash-free sessions) | ≥ 99.7% |
| متوسط تقييم الوصفة | ≥ 4.5 |
| «نجحت الوصفة» | ≥ 90% |
| معدل رفض المطابقة (👎 على الاقتراحات) | ≤ 20% |

### 3.4 إيرادات
| المؤشر | الهدف |
|--------|-------|
| تحويل تجريبي → مدفوع | 30–50% (طموح) |
| تحويل نشط → مشترك | ≥ 3% |
| الاحتفاظ السنوي للمشتركين | ≥ 50% |
| LTV/CAC | ≥ 3 |
| تكلفة AI / مستخدم نشط | ضمن الميزانية |

### 3.5 «نجمة الشمال» (North Star Metric)
> **عدد الوجبات المطبوخة فعليًا عبر التطبيق أسبوعيًا (Weekly Cooked Meals).**

تقيس القيمة الحقيقية: تحويل المكونات إلى وجبة، وتربط بين الاستخدام والاحتفاظ والإيراد.

## 4. خطة الاختبار والجودة

| النوع | الوصف |
|-------|-------|
| اختبارات المطابقة | مجموعة ذهبية: 200 سيناريو مخزون ← النتائج المتوقعة تُراجع بشريًا |
| اختبار الوصفات | آلي (مكونات معروفة، وحدات، حساسية) + بشري (تجريب) |
| اختبار اللهجات | 500 جملة صوتية/نصية من لهجات متعددة |
| اختبار الأجهزة | 15–20 جهازًا (اقتصادي/متوسط/رائد، أحجام شاشات، إصدارات نظام) |
| اختبار RTL | لقطات ذهبية (golden) للشاشات الأساسية بالعربية |
| اختبار الأداء | زمن التشغيل، 60fps، استهلاك البطارية في وضع الطهي |
| اختبار الأمان | فحص تبعيات، اختبار اختراق للـ API |
| اختبار الاشتراك | حالات الشراء/الاسترجاع/الانتهاء على الجهازين |

## 5. حوكمة المنتج بعد الإطلاق

- **مراجعة أسبوعية** للمقاييس الأساسية وأعطال الإنتاج.
- **قنوات الدعم:** نموذج داخل التطبيق + بريد، وقت استجابة < 24 ساعة.
- **لوحة ملاحظات المستخدمين** تُحوَّل إلى خارطة الطريق بشفافية.
- **مراجعة ربع سنوية** للمحتوى المنخفض الأداء والفجوات.
- **سياسة إيقاف/ترحيل:** إن توقف أي جزء، يُمنح المستخدم تصديرًا وإشعارًا مسبقًا.
